### 🧠 TrustScan
**A Bias-Aware AI Framework for ASD Neuroimaging and Confidence-Calibrated Abstention**

**Abstract**

TrustScan integrates AI-driven ASD classification with neuroimaging quality assessment.
Confidence calibration and distribution-shift analysis evaluate prediction reliability.
A three-tier abstention mechanism categorizes outputs as **Trusted**, **Reviewed**, or **Withheld**.
A deferral-gap audit examines differential abstention across ASD and control cohorts.

**Key Features**

1. **Neuroimaging Quality Control** — Motion and signal-integrity assessment.
2. **Confidence-Calibrated Prediction** — Reliability-aware ASD classification.
3. **Adaptive Abstention** — Three-tier uncertainty management.
4. **Bias-Aware Evaluation** — Group-wise deferral-gap analysis.

`Python` `Streamlit` `scikit-learn`
